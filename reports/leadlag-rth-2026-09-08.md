# 美股现货 vs 链上永续：第一份完整 RTH 领先滞后测量（2026-09-08）

状态：测量结果，不是交易建议。回答 `reports/leadlag-notes-2026-09-07.md` 第 2 节提出的问题：**美股现货动了以后，链上永续有没有来不及撤的过时挂单，扣费后剩多少，窗口多长。**

edge 定义（扣掉一次 taker 费，HL 0.9 bps，Lighter 两家 0）：
- `buy_edge = (股价中价 − 永续卖一) / 永续卖一`：永续卖单比现货便宜，吃掉它做多。
- `sell_edge = (永续买一 − 股价中价) / 永续买一`：永续买单比现货贵，砸掉它做空。

## 2. 主结论

**1. 全天的 edge 几乎全部是持续性基差，不是滞后。** 三家永续相对现货有一个整天不动的偏移，方向和大小按品种、按交易所各不相同：

| 品种 | HL xyz | Lighter | Lighter RH |
|---|---|---|---|
| NVDA | 约平（sell p50 −0.2） | **高 9.4 bps** | **高 9.5 bps** |
| TSLA | 高 0.9 | **高 5.7** | **高 4.2** |
| MU | **高 3.5** | **高 10.4** | **高 6.4** |
| SNDK | **低 3.6** | 高 2.8 | 低 1.7 |

（表中数字是 time-weighted p50，"高"= 永续在现货之上，对应 `sell_edge` 为正；"低"= 永续在现货之下，对应 `buy_edge` 为正。）

这解释了为什么「顺着偏移方向」的窗口一开就是几分钟到几小时（NVDA Lighter sell 窗口 p50 354 秒、最长 3.3 小时），也解释了为什么这些方向上的朴素跟随全部亏损：进场时 edge 为正是因为基差，5 秒后基差还在，赚不到收敛，只付了半个价差。这类偏移属于基差 / 资金费题目，已由 carry 分析覆盖，不在本稿范围。

**2. 真正的过时挂单（逆着基差方向出现的窗口）存在，但很少、很短。** 把「与基差方向相反」的那一侧单独看：

| 品种 / 腿 / 方向 | 窗口数 | 每小时 | 持续 p50 / p90 / max (ms) | 朴素跟随：笔数 / 胜率 / 均值 bps / 合计 bps |
|---|---:|---:|---|---|
| TSLA HL 买 | 135 | 25.6 | 155 / 518 / 1059 | 135 / **79.3%** / **+3.14** / **+423.5** |
| SNDK HL 卖 | 99 | 18.8 | 120 / 466 / 1037 | 97 / 63.9% / +2.38 / +231.1 |
| NVDA HL 买 | 28 | 5.3 | 202 / 497 / 945 | 28 / 46.4% / +0.76 / +21.3 |
| MU HL 买 | 14 | 2.7 | 154 / 505 / 799 | 14 / 50.0% / −0.65 / −9.1 |
| TSLA Lighter RH 买 | 4 | 0.8 | 48 / 101 / 103 | 4 / 100% / +15.55 / +62.2 |
| NVDA / MU Lighter 与 RH 买 | 6 至 9 | 1 至 2 | 54 至 91 / 116 至 180 / ≤ 220 | 均为负或样本过小 |

特征：只在 **HL xyz** 上成规模出现（每小时 3 至 26 次），持续时间中位数 120 至 200 毫秒、最长不到 1.1 秒；Lighter 两家几乎没有（每小时 1 至 2 次，持续不到 100 毫秒）。TSLA 和 SNDK 的 HL 侧一天分别累计 +424 和 +231 bps（按每次 1 单位名义、5 秒后按中价平仓、扣两次 0.9 bps 计），是本次唯一为正的信号。

**3. 互相关看不出 HL 以外的滞后。** 100 毫秒收益率互相关的峰值相关系数只有 0.02 至 0.11。HL 的峰值在 **+300 至 +400 毫秒**（永续跟随现货），Lighter 两家在 **−100 至 −200 毫秒**：以富途送到我们手上的股价为基准，Lighter 的报价更新**不比它慢**。考虑到交易所到富途约 240 毫秒、富途到新加坡再加一段，Lighter 做市商拿的股价源比我们快，这条线上对 Lighter 没有速度优势。

**4. 极值是数据伪影。** 各表 max 一列出现 200 至 375 bps 的值（TSLA HL sell max 371），来自个别异常打印或簿快照，占时长 0.01% 以下，不影响分位数，但下一版应过滤。

## 3. 偏差来源（都朝「低估机会」或「低估延迟」方向）

1. **机器在新加坡**，不是美东。HL 主节点在东京、富途接入点在新加坡 / 香港，链路和真正部署时不一样；观测到的 150 至 200 毫秒窗口是「新加坡看到的窗口」，不等于美东可吃到的窗口。
2. **富途只有 Nasdaq + NYSE Arca 两家**，不是 NBBO。对 Nasdaq 上市的这四只影响有限，但摆盘合成有 8 至 13% 的时间两家交叉，已退回最新一家处理。
3. **交易所到富途约 240 毫秒**（p50，来自盘中抽样；p90 约 400 至 540 毫秒）。这是这家数据源的分辨率下限，HL 测出的 +300 毫秒滞后与它同量级，不能据此断言 HL 比现货慢 300 毫秒。
4. 缺开盘后 74 分钟，而开盘是滞后最可能出现的时段。
5. 朴素跟随没有考虑挂单量、我们自己的下单延迟、以及被识别为有毒流量后的对手方反应；胜率 79% 的 135 笔是纸面上限。
