# NautilusTrader 框架入门｜学习计划

## 学习目标

学完后能够：

1. 说明行情、策略、风控、执行、账户与持仓分别由哪个模块负责。
2. 从一条盘口更新追踪到策略回调、下单命令、成交回报和持仓更新。
3. 找到当前安装版本中的相关源码，并区别 v1 与 v2 的接口。
4. 区分行情可用、模拟通过、测试网可用与主网执行可靠这几种证据。
5. 说明新增 Aster 适配器需要实现什么，以及框架已经提供什么。

## 学习路径

1. 系统地图：一条行情如何变成交易，模块如何协作。
2. 最小只读策略：配置、节点、订阅、回调、日志及生命周期。
3. 行情与数据模型：Instrument、精度、L1/L2/L3、快照与增量、时间戳。
4. 订单与执行：命令、事件、状态机、IOC、部分成交、结果未知。
5. 账户、组合、风控与对账：跨所双腿状态、敞口、恢复与停机。
6. 回测与模拟：历史事件、模拟时钟、成交模型、费用、延迟与真实性边界。
7. 适配器开发：对照 Binance、Hyperliquid、Lighter，拆解 Aster 接入任务。
